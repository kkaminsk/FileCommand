VERIFICATION
============

This package downloads the FileCommand installer from the project's official
release location at install time; no binaries are embedded in the .nupkg.

Package version : <VERSION>
Download URL    : <RELEASE_URL>/FileCommandSetup.exe
SHA-256         : <SHA256>

To verify independently:

1. Download FileCommandSetup.exe from the URL above.
2. Compute its hash:

     Get-FileHash .\FileCommandSetup.exe -Algorithm SHA256

3. Confirm the hash matches the SHA-256 value above. The same value is
   passed to Install-ChocolateyPackage in tools\chocolateyInstall.ps1 as
   checksum64, so Chocolatey enforces it on every install.

FileCommandSetup.exe is a WiX Burn bootstrapper signed by Big Hat Group Inc.
via Azure Trusted Signing. You can additionally verify the Authenticode
signature:

     Get-AuthenticodeSignature .\FileCommandSetup.exe

The installer is also distributed as the project's winget package
(BigHatGroup.FileCommand); both channels wrap the same signed artifact.
