## 3. Core — built-in editor buffer (`filecommand-core`)
- [x] 3.1 Add the editor model: in-memory `Vec<Line>` buffer with caret (line/col), loaded UTF-8 lossy, plus the pre-load 10 MB size check that redirects ≥10 MB files to the F3 viewer (builtin-editor "Editor invocation and size cap"; design D1).
- [x] 3.2 Detect and record the dominant line ending (CRLF vs LF) on load for per-file preservation (builtin-editor "Save in place …"; design D2).
- [x] 3.3 Implement insert vs overwrite text-entry modes with a toggle and derived header indicator state (builtin-editor "Insert and overwrite text entry").
- [x] 3.4 Implement line-based selection as an `[anchor_line, cursor_line]` range anchored by Mark, plus whole-line cut, copy, and paste against a line clipboard (builtin-editor "Line-based selection with cut, copy, and paste"; design D1).
- [x] 3.5 Implement literal (non-regex) search and search-and-replace over the buffer, matching metacharacters literally and marking the buffer modified on replace (builtin-editor "Search and search-and-replace without regex").
- [x] 3.6 Implement single-level undo as exactly one prior-state snapshot swap, capturing before each edit and never restoring more than one level (builtin-editor "Single-level undo"; design D1).
- [x] 3.7 Implement F2 save-in-place: write UTF-8 using the recorded line ending, clear modified state, all fs access via the narrow fs trait / `\\?\` long-path seam (builtin-editor "Save in place …"; design D2/D9).
- [x] 3.8 Derive the modified flag from `buffer != saved_snapshot` and expose save-on-exit intent so F10 with unsaved changes signals a confirm rather than exiting (builtin-editor "Modified indicator and save-on-exit prompt"; design D2).

## 5. Core — quicksearch: type-ahead jump and fuzzy directory jump
- [x] 5.1 Add type-ahead mode state to `quicksearch`/`panel`: Alt+letter seeds the pattern and jumps the cursor to the first matching entry (holding position when none match) (type-ahead-jump "Entering type-ahead mode with Alt+letter").
- [x] 5.2 Extend/shorten the type-ahead pattern with plain printable keys and Backspace, re-jumping the cursor to the first match (holding on no-match, staying active on empty) (type-ahead-jump "Extending the pattern with printable keys", "Shortening the pattern with Backspace").
- [x] 5.3 Implement type-ahead exit on Esc or any movement key, with the movement key still applied to the cursor and printable keys returning to command-line routing afterward (type-ahead-jump "Exiting type-ahead and restoring command-line routing"; design D5).
- [x] 5.4 Implement the fuzzy directory-jump index in `quicksearch`: subsequence matching of visited-directory paths against a typed pattern, empty pattern showing all, all matching logic terminal-free (fuzzy-jump "Fuzzy matching of visited directories").
- [x] 5.5 Implement deterministic frecency ranking (recency × frequency, pinned-clock deterministic) so more recent/frequent directories rank higher (fuzzy-jump "Frecency ranking").
- [x] 5.6 Record every navigated-into directory into the frecency history (increment count, refresh last-visit time) and expose Enter-to-navigate semantics (active panel only; inline read-error state on a missing/unreadable target) (fuzzy-jump "Directory history persistence" navigation-record scenario, "Enter navigates the active panel").
- [x] 5.7 Persist directory frecency in `history.json` (platform config dir, atomic write, shared with command history), load on startup, and fall back to empty on absent/malformed file (fuzzy-jump "Directory history persistence"; design D6).
